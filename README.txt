# NOVA — Premium Agency Website

Files:
- index.html — complete website structure
- style.css — responsive premium styling
- script.js — mobile navigation, scroll reveals, dynamic year, and working contact form

How to run:
1. Extract the ZIP.
2. Open index.html in any modern browser.

Notes:
- No external image files are required. The hero and project visuals are built with CSS, so the site works immediately without broken image links.
- The contact form validates fields and opens the visitor's default email client using mailto.
- Replace hello@novastudio.co and phone number in index.html with your real agency details.
- Replace social '#' links with your real profiles.
